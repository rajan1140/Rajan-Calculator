# Rajan-Calculator 🧮
A beautiful, fast calculator built with Python & Streamlit

## Live Demo - [Click Here](https://rajan-calculator-nbezdx8hwxpfspdr59hhtp.streamlit.app)
## Features
- Basic + Scientific calculation
- Keyboard support
- Mobile friendly UI

## How to run locally
pip install -r requirements.txt
streamlit run calculator.py
